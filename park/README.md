# 🅿️ Park

This folder keeps the plugins and skills that daily practice stopped calling. They are not listed in the marketplace, so Claude Code never installs or loads them. They stay here as a record of attempts, and as ideas that may be worth revisiting later.

A parked skill comes back by moving it into `dstoic/skills/` and bumping the dstoic version. No new themed plugin gets created for it. Links inside parked folders may point to paths that moved, since they were left untouched.

"Last use" comes from the session transcripts available on 2026-11-18, which start on 2026-09-18. A dash means no use was recorded in that window.
