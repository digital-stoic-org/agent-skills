# 🧠 dstoic Plugin — TL;DR

> ⚠️ Live experiment. My cognitive toolkit — adapt it to your brain.

dstoic is the default plugin of this repo. New or revisited skills land here instead of in a new themed plugin.

## ✨ What

| Part | Purpose |
|------|---------|
| `skills/diverge` | 💡 Opens a problem in rounds: options without any scoring, you react, the next round builds on it |
| `skills/converge` | 🎯 Decides among those options on criteria and weights you set first |
| `agents/devil-advocate` | 😈 Challenges a confident answer before you commit to it |
| `hooks/` | 🪝 tmux notifications, output dumps |
| `scripts/` | 📟 Statusline and its helpers |
| `security/` | 🛡️ Notes on gaps, perimeter, interception and sentinel briefs |

diverge and converge replace the earlier `cognitive:brainstorm`, which did research, ideas and a recommendation in one turn. They share one idea file per topic under `$PRAXIS_DIR/thinking/brainstorms/`, enriched across sessions. The 14 earlier dstoic skills (commit-repo, pick-model, pick-workflow, save/load-context…) were parked in [park/dstoic-skills/](../park/dstoic-skills/) in November 2026, because daily practice no longer called them.
